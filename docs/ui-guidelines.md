# UI Guidelines

## แนวทางภาพรวม

ระบบควรเป็น Mobile-first และ iPad-friendly เพราะลูกค้าส่วนใหญ่จองผ่านโทรศัพท์ ส่วนเจ้าของร้านอาจใช้ iPad หรือแท็บเล็ตที่หน้าร้าน

## โทนภาพ

- พาสเทล
- น่ารัก
- สบายตา
- สะอาด
- ปุ่มชัดเจน
- อ่านง่าย

## หน้าลูกค้า

ควรสั้น กระชับ และกดง่าย

ลำดับหน้าจอ:

```text
ชื่อร้าน Fah Nail
→ เลือกบริการคร่าว ๆ
→ เลือกช่วงเวลาที่สะดวก
→ กรอกข้อมูลติดต่อ
→ ปุ่มจองคิว
→ ข้อความยืนยันว่าร้านจะติดต่อกลับ
```

คำที่ควรใช้:

- เลือกช่วงเวลาที่สะดวก
- จองคิว
- ร้านจะติดต่อกลับ
- ยังไม่ใช่การจองที่ยืนยันแล้ว
- ไม่ว่าง
- เต็มแล้ว

## ปุ่ม

- ปุ่มหลักต้องเด่นที่สุดในหน้า
- ปุ่มช่วงเวลาต้องใหญ่พอสำหรับนิ้วมือ
- ปุ่มที่กดไม่ได้ต้องแสดงชัดว่าไม่ว่าง
- ห้ามใช้สีจางจนลูกค้าไม่เห็นว่ามีปุ่ม

## หลังบ้านเจ้าของร้าน

ต้องเน้นใช้งานเร็ว:

- ดูคำขอจองใหม่ได้ทันที
- ยืนยันคิวได้เร็ว
- ลงคิวเองได้ง่าย
- เห็นคิวรายวันชัดเจน
- ใช้บน iPad ได้สะดวก

## ข้อมูลที่ไม่ควรแสดงในหน้าลูกค้า

- ข้อมูล Server
- รายละเอียดฐานข้อมูล
- ข้อมูลลูกค้าคนอื่น
- เบอร์โทรลูกค้าคนอื่น
- LINE หรือ Facebook ของลูกค้าคนอื่น
- จำนวนคิวละเอียดที่ไม่จำเป็น
