# Booking Flow

## Flow ลูกค้า

```text
ลูกค้าเปิดลิงก์จอง
→ เลือกบริการคร่าว ๆ อย่างน้อย 1 รายการ
→ เลือกช่วงเวลาที่สะดวก
→ กรอกชื่อและช่องทางติดต่อ
→ กดจองคิว
→ ระบบบันทึกเป็นคำขอจอง
→ แสดงข้อความว่าร้านจะติดต่อกลับ
```

สถานะหลังลูกค้าส่งคำขอ:

```text
pending_request
```

หมายเหตุสำคัญ:

- ยังไม่ใช่การจองที่ยืนยันแล้ว
- ร้านจะติดต่อกลับเพื่อยืนยันเวลาจริง
- ลูกค้าไม่ต้องล็อกอิน

## Flow เจ้าของร้านยืนยันคิว

```text
เจ้าของร้านเปิดหลังบ้าน
→ ดูคำขอจองใหม่
→ ตรวจบริการและช่วงเวลาที่ลูกค้าเลือก
→ ติดต่อกลับลูกค้าถ้าจำเป็น
→ เลือกเวลาจริง
→ ยืนยันคิว
→ ระบบสร้าง appointment
→ ระบบส่งคิวเข้า Google Calendar
→ ช่วงเวลานั้นกดไม่ได้ในหน้าลูกค้า
```

สถานะที่เกี่ยวข้อง:

```text
pending_request
confirmed
cancelled
completed
rejected
```

## Flow เจ้าของร้านลงคิวเอง

ใช้สำหรับ Walk-in, โทรจอง, LINE หรือ Facebook Messenger

```text
ลูกค้าติดต่อร้านโดยตรง
→ เจ้าของร้านเปิดหลังบ้าน
→ ลงข้อมูลลูกค้า
→ เลือกบริการคร่าว ๆ
→ เลือกวันและเวลาจริง
→ บันทึกคิว
→ ระบบส่งคิวเข้า Google Calendar
→ ช่วงเวลานั้นกดไม่ได้ในหน้าลูกค้า
```

แหล่งที่มาของคิว:

```text
customer_request
walk_in
phone
line
facebook
admin
```

## กติกาการปิดช่วงเวลา

หน้าลูกค้าจะปิดปุ่มช่วงเวลาเมื่อมีคิวที่ยืนยันแล้วทับช่วงเวลานั้น

ตัวอย่าง:

```text
08:00-10:00 ว่าง
10:00-12:00 ไม่ว่าง
12:00-14:00 ว่าง
14:00-16:00 ไม่ว่าง
16:00-18:00 ว่าง
```

หน้าลูกค้าเห็นเพียงคำว่า:

```text
ไม่ว่าง
```

หรือ:

```text
เต็มแล้ว
```

ห้ามแสดงข้อมูลลูกค้าคนอื่น
