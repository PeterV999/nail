# Booking Flow

## Customer Request

```text
ลูกค้าเปิดหน้าจอง
→ เลือกบริการ
→ เลือกวันและช่วงเวลา
→ กรอกชื่อและช่องทางติดต่อ
→ ยินยอมเงื่อนไขความเป็นส่วนตัว
→ ส่งคำขอจอง
→ ระบบบันทึกลง booking_requests
→ เจ้าของร้านเห็นคำขอในหลังบ้าน
```

คำขอจากลูกค้ายังไม่ใช่คิวที่ยืนยันแล้ว

## Owner Confirms Request

```text
เจ้าของร้านเปิดคำขอ
→ กดยืนยันคิว
→ ระบบสร้าง appointment status confirmed
→ ระบบเปลี่ยน booking_request เป็น confirmed
→ คิวแสดงในตารางคิวร้านทันที
→ ช่วงเวลานั้นไม่ว่างในหน้าลูกค้า
```

## Owner Rejects Request

```text
เจ้าของร้านเปิดคำขอ
→ กดปฏิเสธ
→ ระบบเปลี่ยน booking_request เป็น rejected
→ คำขอออกจากรายการรอยืนยัน
```

## Owner Creates Appointment

```text
เจ้าของร้านลงคิวเอง
→ กรอกชื่อลูกค้า ช่องทางติดต่อ วัน เวลา และบริการ
→ ระบบสร้าง appointment status confirmed
→ คิวแสดงในตารางคิวร้านทันที
→ ช่วงเวลานั้นไม่ว่างในหน้าลูกค้า
```

## Owner Cancels Appointment

```text
เจ้าของร้านกดยกเลิกคิว
→ ระบบเปลี่ยน appointment เป็น cancelled
→ คิวไม่ถูกนับเป็นช่วงเวลาที่จองแล้ว
→ หน้าลูกค้าเห็นช่วงเวลานั้นว่างอีกครั้ง
```
