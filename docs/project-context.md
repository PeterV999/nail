# Project Context

## ชื่อโปรเจกต์

Fah Nail Booking Platform

## เป้าหมาย

สร้างระบบจองคิวและบันทึกคิวสำหรับร้านทำเล็บ โดยเริ่มจากร้าน **Fah Nail** ก่อน แล้ววางโครงสร้างให้ต่อยอดเป็นระบบ SaaS สำหรับร้านอื่นเช่าใช้รายเดือนได้

## แนวคิดหลัก

ลูกค้าไม่จำเป็นต้องล็อกอิน เพราะร้านต้องการนำลิงก์จองคิวไปวางบนโซเชียล เช่น LINE, Facebook, Instagram หรือหน้าโปรไฟล์ร้าน

การจองจากลูกค้าจะเป็นแบบ **ส่งคำขอจอง** ไม่ใช่การยืนยันคิวทันที เจ้าของร้านต้องเป็นคนตรวจสอบและยืนยันเวลาจริงอีกครั้ง

## ขอบเขตที่ต้องมี

- หน้าจองคิวสาธารณะสำหรับลูกค้า
- หน้าเจ้าของร้านแยกจากหน้าลูกค้า
- ลูกค้าเลือกบริการคร่าว ๆ อย่างน้อย 1 รายการ
- ลูกค้าเลือกช่วงเวลาที่สะดวก
- ลูกค้ากรอกข้อมูลติดต่อ
- เจ้าของร้านดูคำขอจอง
- เจ้าของร้านยืนยัน ปฏิเสธ หรือติดต่อกลับ
- เจ้าของร้านลงคิวเองได้
- ระบบบันทึกคิวที่ยืนยันแล้ว
- ช่วงเวลาที่มีคิวแล้วต้องกดไม่ได้ในหน้าลูกค้า
- ตารางคิวร้านหลังยืนยันคิว
- จัดการบริการได้จากหลังบ้าน
- จัดการผลงานร้านได้

## เทคโนโลยีที่เลือก

- GitHub สำหรับเก็บโค้ดและเอกสารกลาง
- Supabase สำหรับฐานข้อมูล ระบบจัดเก็บรูป และ authentication ในอนาคต
- Cloudflare สำหรับโดเมน ความเร็ว ความปลอดภัย และป้องกันบอท
- ตารางคิวในระบบสำหรับแสดงคิวที่ยืนยันแล้วของร้าน

## URL หลักของระบบ

- `/` สำหรับหน้า preview/รายการตัวอย่างของแพลตฟอร์ม ไม่ใช่หน้าจองร้านจริง
- `/fah` สำหรับหน้าจองคิว Fah Nail แบบสั้นสำหรับแปะ social และ map ไปยัง shop slug `fah-nail`
- `/fah-owner` สำหรับหลังบ้าน Fah Nail แบบสั้นสำหรับเจ้าของร้าน
- `/{shopSlug}` สำหรับหน้าจองคิวของแต่ละร้านในอนาคต
- `/{shopSlug}-owner` สำหรับหลังบ้านของร้านนั้นเท่านั้น
- `/b/{shopSlug}`, `/book/{shopSlug}`, `/o/{shopSlug}`, และ `/dashboard/{shopSlug}` ยังรองรับเป็น route เก่า
- `/register` สำหรับร้านใหม่ลงทะเบียน
ชื่อไฟล์ `index.html` และ `owner.html` เป็นรายละเอียดภายในของ static hosting ไม่ควรใช้เป็น URL ที่ส่งให้ลูกค้าหรือเจ้าของร้าน

## หลักการออกแบบ

- Mobile-first
- iPad-friendly
- UX/UI โทนพาสเทล น่ารัก สบายตา
- ปุ่มต้องชัดเจน เห็นง่าย กดง่าย
- ข้อมูลลูกค้าไม่แสดงสาธารณะ
- ลูกค้าไม่เห็นหลังบ้านหรือปุ่มเข้าหน้าร้าน
- ไม่แสดงข้อมูล Server หรือรายละเอียดเทคนิคในหน้าลูกค้า
