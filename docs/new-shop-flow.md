# Flow เพิ่มร้านใหม่

เอกสารนี้ใช้ตรวจขั้นตอนเพิ่มร้านใหม่บน production ให้จบจริง โดยไม่ต้องแก้ SQL เองในงานปกติ

## ขั้นตอนสำหรับเจ้าของร้าน

1. เปิด `/register`
2. เข้าสู่ระบบด้วย Google
3. กรอกชื่อร้าน, URL ร้าน, และช่องทางติดต่อ
4. กดสร้างร้าน
5. ระบบต้องแสดงลิงก์หน้าลูกค้า `/{shopSlug}` และหลังบ้าน `/{shopSlug}-owner`
6. เจ้าของร้านเปิด `/{shopSlug}-owner` แล้วต้องเห็นหลังบ้านของร้านตัวเองทันที

## สิ่งที่ระบบต้องสร้าง

- ร้านใหม่ใน `shops`
- สิทธิ์เจ้าของร้านใน `shop_members` เป็น `owner`
- บริการเริ่มต้นที่เปิดใช้งาน
- ช่วงเวลาจองเริ่มต้นที่ร้านแก้เองได้
- URL หน้าลูกค้าและหลังบ้านจาก `shopSlug`

## Acceptance Criteria

- ลูกค้าจองผ่าน `/{shopSlug}` ได้
- เจ้าของร้านเห็นคำขอใน `/{shopSlug}-owner`
- เจ้าของร้านยืนยันคิวแล้วคิวขึ้นตารางทันที
- เจ้าของร้านเปิด/ปิดบริการแล้วหน้าลูกค้าอัปเดต
- เจ้าของร้านเปิด/ปิดช่วงเวลาแล้วหน้าลูกค้าอัปเดต
- เจ้าของร้านร้าน A ต้องไม่เห็นข้อมูลร้าน B

## Checklist ก่อนเปิดร้านใหม่ให้ใช้จริง

- [ ] URL ร้านอ่านง่ายและไม่ซ้ำ
- [ ] เจ้าของร้าน login ได้
- [ ] เบอร์หรือช่องทางติดต่อร้านถูกต้อง
- [ ] บริการเริ่มต้นถูกต้อง
- [ ] ช่วงเวลารับจองตรงกับร้านจริง
- [ ] ทดสอบจองจริง 1 รายการและยกเลิกข้อมูลทดสอบหลังจบ
